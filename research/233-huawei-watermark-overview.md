# 华为手机水印方案总览

> 调研时间：2026-05-21  
> 数据来源：华为开发者文档
> 可信度等级：★★★★★（高）

---

## 一、概述

华为手机相机水印功能支持在拍照和录像时添加水印信息，包括设备型号、拍摄参数、时间、地点、自定义文本等内容。HarmonyOS 6.0版本中，照片水印与视频水印相互独立，分开控制。

**核心特点**：
- 照片水印与视频水印独立控制
- 支持云推水印（OTA动态下发）
- 采用鸿蒙ImageEffect框架进行底层渲染
- 支持多种水印类型和参数配置

## 二、水印分类

### 2.1 按类型分类

| 类型 | 类型值 | 说明 |
|------|--------|------|
| 通用水印 (COMMON) | 0 | 包含内嵌水印、画框水印等 |
| 个性水印 (INDIVIDUALITY) | 1 | 个性化定制水印 |
| 限时水印 (TIME_LIMIT) | 2 | 节日水印等时效性水印 |

## 三、拍摄方式支持情况

### 3.1 照片水印支持

| 水印类型 | 后置拍照 | 前置拍照 | 专业模式 |
|----------|----------|----------|----------|
| 通用水印 | ✅ | ✅ | ✅（非RAW） |
| 个性水印 | ✅ | ✅ | ✅（非RAW） |
| 限时水印 | ✅ | ✅ | ✅（非RAW） |

### 3.2 视频水印支持

- **仅支持内嵌通用水印**（ID: COMMON_INNER）
- 默认参数不可调
- 支持前置摄像头独立水印资源

### 3.3 不支持水印的场景

1. 非手机/TV设备
2. Picker模式
3. PRO模式 + RAW格式
4. 全景模式 (PANORAMA)
5. VLOG模式
6. 慢动作模式（不支持录像水印时）

### 4.1 基础路径

| 路径 | 说明 |
|------|------|
| `/sys_prod/resource/camera` | 默认水印资源路径 |

## 五、架构设计

### 5.1 整体架构

```
┌─────────────────────────────────────────────────────────────────┐
│                        应用层 (ArkTS)                            │
│  ┌─────────────┐    ┌──────────────┐    ┌───────────────────┐   │
│  │ Watermark   │───▶│ Watermark    │───▶│ Watermark         │   │
│  │ Service     │    │ Operation    │    │ Function          │   │
│  └─────────────┘    └──────────────┘    └───────────────────┘   │
│         │                   │                    │               │
│         ▼                   ▼                    ▼               │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │              ImageEffect 数据结构构建                     │    │
│  └─────────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────────┘
                              │ NAPI 调用
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                     Native层 (C++)                              │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │              ImageEffectWaterMark                         │    │
│  └─────────────────────────────────────────────────────────┘    │
│                              │                                   │
│                              ▼                                   │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │              HarmonyOS ImageEffect API                   │    │
│  └─────────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────────┘
```

### 5.2 处理流程

1. **数据准备**：收集拍摄参数、时间、地点、XMAGE风格等信息
2. **数据构建**：根据水印类型构建WatermarkFunctionValue对象
3. **序列化配置**：生成ImageEffect配置JSON
4. **底层渲染**：通过OH_ImageEffect API进行渲染
5. **数据持久化**：水印数据随照片保存到相册

### 5.3 滤镜类型映射

| ImageEffect Name | Filter Name | 水印类型 |
|------------------|-------------|----------|
| brandWaterMark | InplaceSticker | COMMON_INNER |
| brandWaterMark | TimingSticker | 时间/地点信息 |
| frameWaterMark | FrameSticker | COMMON_BORDER_BOTTOM |
| XtStyleWaterMark | XtStyleSticker | XMAGE风格水印 |
| frameWaterMark | PersonalizedStickerStyle1 | 个性下边框 |
| frameWaterMark | SpringFestival2026Sticker | 节日水印 |

### 5.4 录像水印处理

录像水印采用独立技术路径：
1. 预加载水印资源（dm.png）
2. 根据视频尺寸动态缩放
3. 计算水印位置（基于最小边缩放）
4. 通过media.WatermarkConfig配置给录像引擎

## 六、小结

华为手机水印方案具有以下特点：

1. **分类清晰**：通用水印、个性水印、限时水印三类，覆盖多种使用场景
2. **参数灵活**：支持设备名、拍摄参数、时间、地点、自定义文本等多维度配置
3. **架构合理**：采用ArkTS应用层 + Native渲染层的分层架构，通过ImageEffect框架实现高性能渲染
4. **资源管理完善**：预置资源与云推资源结合，支持OTA动态更新
5. **场景覆盖全面**：支持后置/前置拍照、录像等多种场景，并针对不支持场景有明确限制

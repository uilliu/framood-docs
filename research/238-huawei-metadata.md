# 华为照片元数据调研报告

> 调研时间：2026-05-21
> 数据来源：华为开发者文档
> 可信度等级：★★★★★（高）

## 一、概述

华为手机拍摄的照片采用多层数据结构存储，包含图像数据和元数据两大类。本文档基于华为开发者文档，详细解析Picture数据结构及其与水印功能的关联。

华为照片支持JPEG和HEIF两种存储格式，其中HEIF格式采用box结构化存储，具有更强的扩展性。

## 二、Picture数据结构

### 2.1 图像数据层

| 数据类型 | 存储格式 | 说明 |
|---------|---------|------|
| 基础图（SDR） | 必选 | 基础图像数据，火龙果模式下保存风格图 |
| GainMap | 可选 | HDR增益图，用于HDR显示 |
| DepthMap | 可选 | 深度数据（float16/32），大光圈/人像模式产生 |
| Unrefocus图 | 可选 | 重对焦图像，大光圈/人像模式产生 |
| 线性图 | 可选 | 光斑虚化用，1/16尺寸16bit YUV420 |
| 水印裁剪图 | 可选 | 支持编辑回退的水印覆盖区域原图 |
| 抓拍图/摇拍图 | 可选 | 一拍多得功能产生 |

### 2.2 元数据层

| 元数据类型 | 说明 | 来源 |
|-----------|------|------|
| Exif | 拍照必须，编辑可选 | 相机 |
| ICC Profile | 色彩信息 | 相机 |
| vivid metadata | 编码用，封装到SEI | 相机 |
| FRAGMENT_METADATA | 水印裁剪图元数据 | 图片编辑 |
| XTSTYLE_METADATA | 火龙果参数（肤色分割图+3D LUT） | 相机 |
| APP7-10 | 维测数据，私有box存储 | 相机 |
| RfDataB | 大光圈元数据 | 相机 |

## 三、元数据字段详解

### 3.1 EXIF标准元数据

EXIF（Exchangeable Image File Format）是照片元数据的核心载体，包含：
- 拍摄参数：光圈、快门、ISO、焦距
- 设备信息：机型、镜头型号
- 时间位置：拍摄时间、GPS坐标
- 图像属性：分辨率、方向

### 3.2 华为私有元数据

```
┌─────────────────────────────────┐
│      HEIF文件结构               │
├─────────────────────────────────┤
│ ftyp (文件类型)                 │
├─────────────────────────────────┤
│ meta (元数据容器)               │
│   ├─ iloc (位置信息)            │
│   ├─ iinf (项目信息)            │
│   └─ iprp (项目属性)            │
├─────────────────────────────────┤
│ mdat (媒体数据)                 │
│   ├─ 基础图像数据               │
│   ├─ GainMap                   │
│   ├─ DepthMap                 │
│   └─ 私有box (APP7-10等)        │
└─────────────────────────────────┘
```

### 3.3 一拍多得元数据

一拍多得功能产生多组元数据：
- **XDRAW4K**：压缩线性图
- **PRIVATE**：私有元数据
- **RFDATAN**：基础图RfData
- **RFDATAS**：抓拍图RfData
- **HDRSNAP**：抓拍HDR元数据

## 四、元数据与水印关联

### 4.1 水印裁剪机制

华为采用FRAGMENT_MAP + FRAGMENT_METADATA实现水印可编辑：

```
┌─────────────────────────────────┐
│ 水印编辑数据流                   │
├─────────────────────────────────┤
│ 1. 添加水印时                    │
│    - 保存被覆盖区域原图           │
│    - 存储为FRAGMENT_MAP          │
│    - 生成FRAGMENT_METADATA       │
├─────────────────────────────────┤
│ 2. 编辑/移除水印时               │
│    - 读取FRAGMENT_MAP            │
│    - 根据FRAGMENT_METADATA定位   │
│    - 恢复原始像素                 │
└─────────────────────────────────┘
```

### 4.2 EXIF在水印中的应用

水印功能从EXIF提取以下信息用于显示：

| EXIF字段 | 水印用途 |
|---------|---------|
| DateTime | 时间水印 |
| GPSLatitude/GPSLongitude | 地理位置水印 |
| Make/Model | 设备型号水印 |
| FNumber/ExposureTime | 拍摄参数水印 |

### 4.3 数据结构示例

```json

    "base_image": "NV12编码数据",
    "gain_map": "HDR增益图（可选）",

  "metadata": {
    "exif": {

      }
    }
  }
}
```

## 五、小结

华为照片元数据采用分层架构设计：
1. **图像数据层**：包含基础图、深度图、GainMap等多层数据
2. **元数据层**：EXIF标准 + 华为私有扩展
3. **水印关联**：通过FRAGMENT_MAP实现可回退编辑

关键技术特点：
- HEIF格式采用box结构，扩展性强
- 水印编辑支持无损回退
- 一拍多得产生多组关联元数据
- 私有元数据以BLOB格式整段读写

## 一、OPPO相机水印方案

### 1.1 水印类型

| 水印类型 | 功能说明 | 可配置项 |
|---------|---------|---------|
| 机型水印 | 显示OPPO品牌及机型型号 | 自动读取设备信息，可隐藏 |
| 时间水印 | 显示拍摄日期和时间 | 支持多种格式 |
| 地点/GPS水印 | 显示拍摄位置信息 | 自动定位或手动输入 |
| 天气水印 | 显示实时天气状况 | 自动获取或手动选择 |
| 自定义文字水印 | 用户编辑个性化文字 | 字数限制、字体可选 |
| 哈苏认证水印 | Find X系列专属联名水印 | 仅限合作机型 |

### 1.2 哈苏联名水印特点

| 特点 | 说明 |
|------|------|
| Logo颜色 | 橙色哈苏品牌标识 |
| 配色方案 | 橙色Logo + 白色文字 |
| 布局位置 | 底部居中显示 |
| 适用机型 | Find X系列（Find X3、Find X5、Find X6等） |
| 视觉定位 | 专业摄影、高端感 |

### 1.3 边框样式

- 经典边框：底部参数条
- 极简边框：单行信息
- 无边框：仅水印信息
